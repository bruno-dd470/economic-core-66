## 1. Введение

### 1.1. Назначение
`economic_core_66` — это саморегулируемое ядро экономической модели, основанной на алгебре Клиффорда Cl(6,6).  
Оно интегрирует:
- **Статический остов Cl(6,0)**: 20 аттракторов, 12 пентад, спектральные наблюдаемые.
- **Динамическое расширение Cl(6,6)**: 144 пентады, 400 совместных аттракторов, оператор перехода T.
- **7 спектральных порогов**, происходящих из исключительной решётки Λ₇₂.
- **Топологическое натяжение** $T = \nabla\eta \cdot \nabla R_{seuil}$, нормализованное к диапазону $[0, 1[$.

### 1.2. Теоретическое позиционирование
Модель опирается на две основополагающие статьи:
1. **AHRN** — *Единая арифметика для трёх онтологий: материя, жизнь и информация* (июнь 2026)  
   Даёт 15 универсальных констант $\beta_k$ и спектральную формулу.
2. **144 пентады** — *Усин и Cl(6,6): 144 пентады для единой реляционной физики* (апрель 2026)  
   Даёт структуру Cl(6,6), оператор T и 7 порогов.

Пакет `economic_core_66` является **операционной реализацией** этих двух статей в экономической области.

### 1.3. Различие Cl(6,0) и Cl(6,6)
| Алгебра | Сигнатура | Роль | Реализация |
| --- | --- | --- | --- |
| **Cl(6,0)** | (6,0) | Статический остов (конфигурации, аттракторы) | Встроено в `economic_core_66.py` |
| **Cl(6,6)** | (6,6) | Динамика (переходы, пороги) | `economic_core_66.py` |

## 4. Быстрый старт

### 4.1. Минимальный пример
```python
from economic_core_66 import EconomicCore66

# Инициализация
core = EconomicCore66(noise_level=0.0, seed=42)

# Конфигурация Китая 2026
config = {
    'P1': -1, 'P2': -1, 'P3': -1, 'P4': -1, 'P5': -1,
    'P6': +1,
    'N1': -1, 'N2': -1, 'N3': -1, 'N4': -1,
    'N5': +1, 'N6': +1,
}
attractor = core.set_from_config(config)
core.set_attractor_geo(attractor)

# Начальная диагностика
core.print_diagnostic()

# Регулирование Cl(6,0)
core.regulate_60(steps=15)
core.print_diagnostic()

# Симуляция истории (необходима для вычисления натяжения)
for i in range(10):
    eta = core.eta_direct() + i * 0.02
    r = core.r_threshold() + i * 0.02
    core.eta_history.append(eta)
    core.r_threshold_history.append(r)

# Переход Cl(6,6)
result = core.apply_T('mixed', intensity=1.0)
print(f"Переход: {result['attracteur_avant']} → {result['attracteur_apres']}")
print(f"Натяжение: {result['tension']:.6f}")
print(f"Преодолённые пороги: {result['seuils_franchis']}")

# Финальная диагностика
core.print_diagnostic()
```

## 5. Детальное описание модулей

### 5.1. `foundations_ahrn.py`
**Роль:** Даёт универсальные константы и спектральную формулу.  
**Константы:** `BETA_K` (15 значений), `SEUILS_SPECTRAUX` (7 значений), `LAMBDA_NUC`, `LAMBDA_E`, `LAMBDA_ECO`.  
**Функции:** `spectral_energy()`, `spectral_energy_vectorized()`, `validate_foundations()`, `print_validation_report()`.

### 5.2. `pentads_144.py`
**Роль:** Строит 144 пентады (12 базовых × 12 спектральных листов).  
**Константы:** `FEUILLETS`, `PENTADES_BASE`, `ATTRACTEURS`, `CEINTURE_POSITIVE`, `CEINTURE_NEGATIVE`, `SEUILS_POLAIRES`.  
**Функции:** `build_144_pentads()`, `build_144_pentads_by_sector()`, `get_pentad()`, `validate_pentads()`.

### 5.3. `attractors_400.py`
**Роль:** Строит 400 совместных аттракторов (20 экономических × 20 географических).  
**Функции:** `build_400_attractors()`, `get_attractor_400()`, `attractor_distance_400()`, `find_nearest_attractor_400()`, `validate_attractors_400()`.

### 5.4. `operateur_T.py`
**Роль:** Реализует оператор перехода T.  
**Класс `OperateurT`:** Методы `apply_structure()`, `apply_fire()`, `apply_water()`, `apply_mixed()`, `apply()`, `_choose_best_target()`, `check_conservation()`.  
*Примечание:* `_choose_best_target` применяет штраф к крайним аттракторам (3P, 3N), предпочитая более стабильные аттракторы 2P+1N.

### 5.5. `seuils_spectraux.py`
**Роль:** Управляет 7 спектральными порогами.  
**Константы:** `SEUILS_SPECTRAUX`, `ROLES_SEUILS`, `CORRESPONDANCE_POLARITE`.  
**Класс `GestionnaireSeuils`:** Методы `try_cross()`, `cross_all_possible()`, `get_crossed()`, `get_current_polarity()`.  
*Примечание:* `cross_all_possible(tension)` преодолевает **только один** порог за раз (следующий непреодолённый), следуя последовательности 3P → 2P+1N → 1P+2N → 3N.

### 5.6. `tension_topologique.py`
**Роль:** Вычисляет топологическое натяжение $T = \nabla\eta \cdot \nabla R_{seuil}$, нормализованное.  
**Формула:** $T_{norm} = \frac{|\nabla\eta \cdot \nabla R_{seuil}| \cdot \alpha}{1 + |\nabla\eta \cdot \nabla R_{seuil}| \cdot \alpha}$  
**Функции:** `compute_topological_tension()`, `check_threshold_crossing()`, `validate_tension()`.  
**Класс `SuiviTension`:** Отслеживает натяжение в скользящем окне.

### 5.7. `economic_core_66.py`
**Роль:** Главное ядро, интегрирующее все модули.  
**Класс `EconomicCore66`:** Методы `set_from_config()`, `regulate_60()`, `apply_T()`, `diagnose()`, `print_diagnostic()` и др.

## 8. API Reference

### `EconomicCore66`
- `__init__(noise_level=0.0, seed=None)`: Инициализирует ядро Cl(6,6).
- `set_attractor_eco(attractor: str)`: Устанавливает экономический аттрактор (A–T).
- `set_attractor_geo(attractor: str)`: Устанавливает географический аттрактор (A–T).
- `set_from_config(config: Dict[str, int]) -> str`: Определяет аттрактор из словаря конфигурации `{пентада: +1 или -1}`.
- `regulate_60(steps: int = 15, target: Optional[str] = None)`: Регулирование Cl(6,0) по минимальному расстоянию аттрактора.
- `apply_T(composante: str = 'mixed', intensity: float = 1.0) -> Dict`: Применяет компоненту оператора T (`'structure'`, `'fire'`, `'water'`, `'mixed'`).
- `diagnose() -> Dict[str, Any]`: Возвращает полный диагностический словарь со всеми наблюдаемыми (`eta`, `d`, `gap`, `r_threshold`, `frustration`, `tension`, `regime`, `severity`, `state` и др.).
- `print_diagnostic()`: Выводит форматированную диагностику в консоль.

## 9. Ограничения и перспективы

### 9.1. Текущие ограничения
- **Приближения наблюдаемых:** Некоторые наблюдаемые (`d`, `gap`) аппроксимированы простыми формулами. Более строгая реализация потребовала бы полного дискретного оператора Дирака.
- **Именование пентад:** Названия пентад и листов являются предварительными и могут быть уточнены.
- **Калибровка `Λ_eco`:** Экономическая масштабная константа остаётся не откалиброванной по реальным данным.
- **Эмпирическая валидация:** Ядро ещё не тестировалось на реальных экономических наборах данных (например, BNS, BPC).
- **`η_66 = 0.000`:** Спектральная асимметрия Cl(6,6) в настоящее время остаётся нулевой (формула требует пересмотра).

### 9.2. Перспективы
- **Дискретный оператор Дирака:** Реализовать полный оператор Дирака на 144 пентадах для строгого вычисления `d` и `gap`.
- **Решётка Λ₇₂:** Углубить интеграцию собственных значений решётки Λ₇₂. 15 констант $\beta_k$ уже извлечены, но требуется более тонкая калибровка.
- **Реальные данные:** Подключить ядро к потокам реальных экономических данных.
- **Пользовательский интерфейс:** Разработать веб-интерфейс для управления моделью.
- **Расширение на другие плоскости:** Расширить модель на другие пары плоскостей (социальная/экологическая и т.д.).
